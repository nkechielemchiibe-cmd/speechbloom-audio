# SpeechBloom Audio

Audio assets for the SpeechBloom Kids AAC (Augmentative and Alternative Communication) app.

These files are served via GitHub Pages and consumed by the SpeechBloom Kids app
to provide voice narration for AAC tiles, spelling exercises, stories, routines,
and section announcements.

## Structure
- `tile_<key>.mp3` - individual AAC tile word audio
- `spell_<key>.mp3` - spelling exercise word audio
- `letter_<a-z>.mp3` - alphabet letter audio
- `story_<id>.mp3` - storybook narration
- `ann_<section>.mp3` - section announcements
- `phrase_<hash>.mp3` - sentence/phrase combinations
- `teachervoices/` - teacher voice samples for phonics
- `childvoices/` - child voice samples for echo practice
